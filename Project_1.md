## Context

In a procurement operation involving thousands of payment records, purchase orders, and case files, the main challenge was not simply storing information, but transforming it into a reliable tool to monitor the process, detect inconsistencies, and analyze operational performance.

The original solution worked with a database of more than 6,000 records.
For this portfolio, a synthetic version was created to replicate the structure and analytical logic of the project without using confidential information.

---

## The Analytical Challenge

The database contained multiple processing statuses, assigned specialists, dates, amounts, observations, and movements related to payment tracking.

Manual monitoring made it difficult to quickly answer questions such as:

* How many case files are currently being processed?
* How is the workload distributed?
* What is the productivity level of each specialist?
* Which records contain inconsistencies?
* Where are processing delays concentrated?
* What is the financial progress of the process?

## From Operational Data to Management Insights

The project transformed a database primarily used for administrative tracking into a structured source for analysis.

The workflow developed was:

Operational Data → Validation → Cleaning → Automation → Analysis → KPIs → Dashboard

Controls were implemented to detect duplicates, incomplete fields, inconsistencies in dates and amounts, as well as business rules to validate record statuses.

## Productivity Analysis

Indicators were developed to analyze processed volume, workload, assignments, case transfers, and productivity by specialist.

Pivot tables made it possible to explore the information by period, responsible specialist, and process status.

## Payment Tracking

The analysis made it possible to monitor the progress of case files across different stages of the process and consolidate financial indicators related to certified, accrued, and pending amounts.

---

## Dashboard

The dashboard summarizes the main operational indicators:

* Case file volume
* Productivity by specialist
* Workload distribution
* Monthly trends
* Payment status
* Processing times
* Flagged records
* Penalties and control indicators

## Key Findings

The analysis identified differences in workload distribution, concentrations of case files among specialists, records requiring review, and trends in processing volume.

The consolidation of these indicators provided a clearer view of the operational and financial status of the process.
