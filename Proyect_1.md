## Contexto

En una operación de abastecimiento con miles de registros de pagos, órdenes
y expedientes, el reto principal no era únicamente almacenar información,
sino convertirla en una herramienta confiable para monitorear el proceso,
detectar inconsistencias y analizar el desempeño operativo.

La solución original trabajaba con una base de más de 6,000 registros.
Para este portafolio se construyó una versión sintética que reproduce la
estructura y lógica analítica del proyecto sin utilizar información confidencial.

---

## El reto analítico

La base contenía múltiples estados de procesamiento, especialistas responsables,
fechas, montos, observaciones y movimientos asociados al seguimiento de pagos.

El seguimiento manual dificultaba responder rápidamente preguntas como:

- ¿Cuántos expedientes están siendo procesados?
- ¿Cómo se distribuye la carga de trabajo?
- ¿Cuál es la productividad de cada especialista?
- ¿Qué registros presentan inconsistencias?
- ¿Dónde se concentran los retrasos?
- ¿Cuál es el avance financiero del proceso?

## De datos operativos a información de gestión

El proyecto transformó una base utilizada principalmente para seguimiento
administrativo en una fuente estructurada para análisis.

El flujo desarrollado fue:

Datos operativos → Validación → Limpieza → Automatización → Análisis → KPIs → Dashboard

Se implementaron controles para detectar duplicados, campos incompletos,
inconsistencias en fechas y montos, así como reglas de negocio para validar
el estado de los registros.

## Análisis de productividad

Se construyeron indicadores para analizar volumen procesado, carga de trabajo,
asignaciones, derivaciones y productividad por especialista.

Las tablas dinámicas permitieron explorar la información por periodo,
responsable y estado del proceso.

## Seguimiento de pagos

El análisis permitió monitorear el avance de los expedientes a través de
diferentes etapas del proceso y consolidar indicadores financieros asociados
a montos certificados, devengados y pendientes.

## Dashboard

El dashboard resume los principales indicadores operativos:

- Volumen de expedientes
- Productividad por especialista
- Distribución de carga de trabajo
- Evolución mensual
- Estado de pagos
- Tiempos de procesamiento
- Registros observados
- Penalidades y controles

## Principales hallazgos

El análisis permitió identificar diferencias en la distribución de carga,
concentraciones de expedientes por especialista, registros que requerían
revisión y tendencias en el volumen de procesamiento.

La consolidación de los indicadores proporcionó una visión más clara del
estado operativo y financiero del proceso.
